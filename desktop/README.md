# PrefLopLab Randomizer (Windows)

A small always-on-top window showing a number from 0 to 100. It rerolls
itself every 10 seconds, or immediately when you click it — the same thing
the `/randomizer` page does, except a native window can sit above a poker
client that runs full screen.

The built binary lives at `public/PrefLopLab-Randomizer.exe`, so the site
serves it too. Nothing to install: one 65 KB file, no runtime, no registry
entries, no window manager tricks.

## Using it

| | |
| --- | --- |
| Left click | reroll now, and restart the 10 seconds |
| Space / Enter | the same, from the keyboard |
| Left drag | move the window |
| Bottom-right corner | resize (the number scales with it) |
| Right click | menu: reroll, turn always-on-top off, close |
| Esc | close |

The first time you run it Windows SmartScreen will warn that the publisher
is unknown — the exe is not code-signed, and a certificate costs more per
year than this program is worth. **More info → Run anyway.**

## Building

Cross-compiled from Linux; there is no Windows machine in the loop.

```sh
apt-get install mingw-w64
desktop/build.sh
```

`randomizer.ico` is generated by `make_icon.py` (needs Pillow) and is
checked in, so a normal build does not need Python.
